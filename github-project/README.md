# GitHub Project para Dia 2 y W1

Configuracion reproducible del Project **ReqFlow** que cada participante crea bajo su `<OWNER>` (el mismo owner de sus tres repos) durante S3 del Dia 2.

## Campos

- Status: Todo, In progress, In review, Done
- Assignee
- Requirement ID
- Hallazgo origen: Id `H-xx` del `HALLAZGOS.md` del Dia 1
- Lab: S1, S2, S3, W1
- Backend
- Frontend
- Tests
- Evidence
- Gate W1

## Issues

Usa `issue-template.md` para crear una issue por HU (Dia 2) y por requisito de W1. W1 debe tener un requisito distinto por asistente y enlazar su repositorio individual.

## Regla de caso y continuidad

Todo el programa usa **ReqFlow**. El Project se llama `ReqFlow`, se crea el Dia 2 y lo reutilizan los Dias 3 y 4: no se recrea. Cada issue nace de una HU, y cada HU de un hallazgo del Dia 1 (campo `Hallazgo origen`, Id `H-xx`).
